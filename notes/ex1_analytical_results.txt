(a)  WHY THIS IS REASONABLY A 1D DIFFUSION PROBLEM
==============================================================================
Assumptions (stated explicitly):
  A1  Shallow channel: h = 5 um << w = 100 um, so the flow is 2D in the
      x-y plane with a parabolic (Poiseuille) profile; h enters only the
      hydraulic resistance, not the concentration field.
  A2  Stokes flow, laminar, single phase (Re << 1, see below).
  A3  Dilute, non-reacting sugar: pure diffusion with constant D.
  A4  No-flux walls at y = +-w/2 (no sugar leaves through the walls).
  A5  Convective mixing between the two side streams is neglected; the
      only cross-stream mechanism is transverse diffusion.
  A6  The concentration profile is 'frozen' in x: the advective travel
      time along x is ~1e5 times shorter than the longitudinal diffusion
      time, so Pe_x >> 1 and dc/dx ~ 0 (quantified below).

CASE B - COMSOL geometry:
   L = 6 mm,  Q0 = 0.1 uL/min (1.666667e-12 m^3/s)
   channel volume V = L w h              = 3.000000e-12 m^3
   residence time t_res = V/Q0            = 1.8 s
   mean velocity U = Q0/(w h)             = 0.00333333 m/s
   transverse diffusion time (1st eigenvalue) t_diff,y = w^2/(pi^2 D) = 5.06606 s
   longitudinal diffusion time t_diff,x = L^2/D            = 180000 s
   Peclet x: Pe_x = U L/D                  = 100000
   Peclet y: Pe_y = U w/D                  = 1666.67
   Reynolds: Re_h = rho U h/eta           = 1.667e-02 (Re_w = 3.333e-01)
   ratios: t_diff,x/t_res = 100000   t_res/t_diff,y = 0.355306

CASE A - Bruus geometry (flow rate NOT given in the assignment;
   L = 25 mm,  Q0 = 0.1 uL/min (1.666667e-12 m^3/s)
   channel volume V = L w h              = 1.250000e-11 m^3
   residence time t_res = V/Q0            = 7.5 s
   mean velocity U = Q0/(w h)             = 0.00333333 m/s
   transverse diffusion time (1st eigenvalue) t_diff,y = w^2/(pi^2 D) = 5.06606 s
   longitudinal diffusion time t_diff,x = L^2/D            = 3.125e+06 s
   Peclet x: Pe_x = U L/D                  = 416667
   Peclet y: Pe_y = U w/D                  = 1666.67
   Reynolds: Re_h = rho U h/eta           = 1.667e-02 (Re_w = 3.333e-01)
   ratios: t_diff,x/t_res = 416667   t_res/t_diff,y = 1.48044
         the COMSOL flow rate 0.1 uL/min is used as the reference):

General formulas in the (unspecified) total flow Q0:
   t_res(Q0)  = L w h / Q0  -> Case A: 1.250000e-11/Q0 [s],  Case B: 3.000000e-12/Q0 [s]
   U(Q0)      = Q0/(w h)
   Pe_y(Q0)   = U w/D = Q0/(h D)  -> Case B at 0.1 uL/min: 1666.67
   Pe_x(Q0)   = U L/D = Q0 L/(w h D)
   t_diff,y   = w^2/(pi^2 D) = 5.06606 s   (both cases, same w and D)
   t_diff,x   = L^2/D = 3.125e+06 s (Case A), 180000 s (Case B)

Conclusion (the physical argument):
  * Convection along x dominates diffusion along x by Pe_x ~ 100000 (Case B) to 416667 (Case A).
    t_diff,x/t_res = 100000 (Case B): the
    concentration profile has no time to diffuse along a 6 mm channel,
    so c(y) is essentially independent of x over the channel length -
    the profile is 'frozen' in the streamwise direction.
  * Transversally, t_res = 1.8 s (Case B) is a factor
    2.81 SMALLER than the transverse
    diffusion time t_diff,y = 5.066 s: diffusion across
    the width is only PARTLY complete within one residence time, which
    is exactly the regime the H-filter exploits (it sorts on D).
  * Hence dc/dt = D d2c/dy2 with x frozen: a 1D (transverse) diffusion
    problem.  The transverse length scale is w = 100 um; the streamwise
    length scale L does not enter the concentration field at all.

    independent image-sum root (exact erfc form): t1 = 5.8656 s (difference 0.00e+00 s)

B2  Closed form for an INFINITE domain (no walls, free space):
    c(+w/2,t) = c0/2 * erfc(w/(4 sqrt(D t)))
    t1 = 22.7276 s
    achieved c(+w/2, t1)/c0 = 0.30000000
    absolute difference |t1_series - t1_erfc| = 16.862 s
      = 287.47 % of t1_series, 74.19 % of t1_erfc
    ratio t1_erfc / t1_series = 3.8747

    WHY THE TWO DIFFER BY A FACTOR ~4 (both are correct, for different
    geometries):
      * Eq.(1) solves the REAL channel: solid walls at y = +-w/2.
        Sugar that diffuses towards the upper wall is reflected and
        accumulates, so the wall concentration rises quickly.
      * erfc() assumes an UNBOUNDED medium: sugar that diffuses past
        y = +w/2 is simply lost to the exterior, so the wall value lags.
      * Diffusion length sqrt(2 D t1):
          Eq.(1)  : t1 = 5.866 s -> 48.44 um  (= 0.97 w/2)
          erfc    : t1 = 22.73 s -> 95.35 um  (= 1.35 w)
      * The erfc value corresponds to a front that has travelled PAST the
        wall by ~35 % of the channel width, i.e. it is only valid for a
        channel much wider than the diffusion length.  At the 30 %
        level the front has already reached the upper wall, so the wall
        BC matters and Eq.(1) is the physically correct one for the
        H-filter of this assignment.
    => PRIMARY t1 = 5.866 s (Eq. 1).
       erfc cross-check: t1 = 22.73 s (74.2 % longer than Eq. 1).

    Convergence of the series at y = +w/2 (sin((2n-1)pi/2) = +-1):

(c)  COMPARISON WITH THE RELEVANT DIFFUSION TIME
==============================================================================
  t_diff        = w^2/(4 D)    = 12.5 s   (as prescribed)
  t_diff,eigen  = w^2/(pi^2 D) = 5.06606 s   (1st eigenmode)
  t_diff,hw     = w^2/(8 D)    = 6.25 s   (<x^2> = 2Dt with x = w/2)
  (consistency note: <x^2> = 2Dt with x = w/2 gives w^2/(8D) = 6.25 s;
   the prescribed w^2/(4D) is the same estimate with the <x^2> = 4Dt
   convention.)

  t1 / t_diff        = 0.469248
  t1 / t_diff,eigen  = 1.15782
  t1 / t_diff,hw     = 0.938496
  (same ratios for the infinite-domain value t1 = 22.73 s:
   t1_erfc/t_diff = 1.81821, t1_erfc/t_diff,eigen = 4.48625, t1_erfc/t_diff,hw = 3.63642)

  Does it make sense?  Yes - with one honest caveat:
   * t1 = 5.866 s EXCEEDS the first-eigenmode transverse
     relaxation time t_diff,eigen = 5.066 s (ratio 1.1578).
     This is the meaningful statement: diffusion only REDISTRIBUTES the
     sugar, it cannot create a step, so the 30 % level can only be
     reached after the slowest (fundamental) transverse mode has had
     time to relax, i.e. after at least one eigen-relaxation time.
   * t1 = 5.866 s is slightly BELOW t_diff,hw = 6.25 s = the time for the front to travel the
     half width w/2, and below the prescribed w^2/(4D) = 12.5 s.
     Reason: the 30 % WALL value is reached while the front is still
     spreading (it is a tail value, not the front), and the reflecting
     wall of the real channel accelerates it.  For the infinite-domain
     model the ordering is the textbook one: t1_erfc = 22.73 s
     > t_diff = 12.5 s (ratio 1.818).
   * Order-of-magnitude check: at t1 the front has travelled
     sqrt(2 D t1) = 48.44 um
     ~ w/2 = 50 um, i.e. exactly the distance from the interface to the
     upper wall.  The 30 % level at the wall is reached when the
     spreading front has just arrived there - self-consistent.

(e)  DRIVING PRESSURE NEEDED FOR 30 % SUGAR IN THE UPPER EXIT
==============================================================================
MODEL - stated explicitly, with the algebra.

  The main channel carries the total flow Q0; the two side channels feed
  it (sugar below, water above) and the two exit channels leave it.
  With identical side and exit channels the inlet split is
      alpha = Q_sugar/Q0 = 1/2,   the exit split f_up = Q_up/Q0 = 1/2,
  and the interface sits on the midline y = 0, which is exactly the
  initial condition of Eq. (1).  In the main channel the transverse
  velocity is u(y) = (3/2) U (1 - (2y/w)^2), U = Q0/(w h), and the
  steady state obeys  u(y) dc/dx = D d2c/dy2.

  (1) Along the channel the transverse sugar FLUX is conserved:
      d/dx int_0^{w/2} u(y) c(y,x) dy = D [dc/dy]_{y=0}^{w/2} = 0,
      because the walls at y = +-w/2 are no-flux.
  (2) The upper exit carries flow Q_up = f_up Q0 and collects the sugar
      that has crossed the interface, so its concentration is
      c_up = Phi_up(L) / (f_up Q0),
      Phi_up(L) = int_0^{w/2} u(y) c(y, t_res) dy.
  (3) The total sugar molar flow entering is n_s = alpha Q0 c0, so the
      fraction that crossed is F_cross = Phi_up/(alpha Q0 c0) and
          c_up/c0 = F_cross * alpha / f_up.                     (*)
  (4) For the symmetric device (alpha = f_up = 1/2) (*) reduces to
          c_up/c0 = F_cross(t_res),
      i.e. the 30 % condition means that 30 % of the entering sugar has
      crossed the midline within the residence time.  F_cross is given
      by the same series as Eq. (1).
  (5) The residence time is set by the flow rate, t_res = L w h/Q0, so
      the 30 % condition fixes Q0, and then dp = Q0 R_h.

  ALTERNATIVE READING (flagged): the assignment wording ('the flow split
  that gives 30 % sugar in the upper exit') can also be read as: keep
  Q0 fixed and tune the inlet split alpha instead.  That is solved
  below for the COMSOL operating point; note that alpha > 1/2 means
  the sugar stream itself is wider than half the channel, so the sugar
  reaches the upper exit by ADVECTION, not by diffusive crossover -
  which defeats the purpose of an H-filter.  The symmetric device
  (alpha = 1/2) with a suitable Q0 is therefore the defensible
  reading, and the residence-time criterion is used as primary.

  E1  PRIMARY: residence-time criterion (symmetric device, alpha=1/2)

  E3  ALTERNATIVE READING: fixed Q0, tune the inlet split alpha.
      The interface between the two side streams sits at y*; with the

      channels, divide line y=0) then sees the flow-weighted average
      c_up(alpha) = int_0^{w/2} u c dy / int_0^{w/2} u dy, evaluated with

      c_up(alpha) = 0.30 c0 at the COMSOL operating point

      QUANTITATIVE CAVEAT: alpha > 1/2 by 0.0420, so a

      upper exit without ever diffusing.  Of the 30 % delivered,
      only 86.0 % of the

      So this branch is only weakly 'sorting' - it is not the
      intended operating regime.  The physically meaningful design

      rate, see E1.

  E4  FALLBACK ESTIMATE (the simple split-only model requested):
      If the upper exit carries a fraction f_up of the total flow Q0 and
      the sugar entering at the bottom is (to first order) retained in
      its own stream, then the sugar concentration in the upper exit is
      set by the diffusive exchange alone:
          c_up/c0 = F_cross(t_res) * alpha / f_up = 0.30
      i.e.   alpha = 0.30 f_up / F_cross(t_res),
      with F_cross(t_res) = c_up(t_res)/c0 from the same series
      (symmetric interface, alpha = 1/2):
        at the COMSOL operating point (t_res = 1.8 s):
          F_cross = 0.266845 (flux-weighted), alpha = 0.562125
          F_cross = 0.214070 (area-weighted),  alpha = 0.700705
        => a solution EXISTS, but only for alpha > 1/2, i.e. the sugar
        side stream must carry MORE than half the total flow, which
        pushes the interface above the midline so that part of the
        sugar reaches the upper exit by ADVECTION rather than by
        diffusion.  That is the degenerate branch, and it confirms that
        the physically meaningful design point is the symmetric device
        (alpha = 1/2) running at a LOWER flow rate (see E1).
        At the 30 % residence time (t1 = 5.866 s, the
        wall criterion) the crossover fractions are F_cross = 0.397371 (flux) / 0.372671 (area);

BONUS - critical diffusion coefficient and largest sortable particle
     (cross-check for the COMSOL part (a)-(c); not part of a-e)
==============================================================================
  The crossover is governed by the single dimensionless group
      x = pi^2 D t_res / w^2.
  Two common definitions of the critical diffusion coefficient D_c:
   (i)  'classical' crossing criterion: the diffusion front travels the
        half width w/2 in the residence time, <x^2> = 2 D t_res:
            D_c = w^2/(8 t_res)
   (ii) 'wall criterion' used in this assignment (30 % at the upper
        wall at the end of the channel), i.e. x = x(t1) = 1.1578:
            D_c = x(t1) w^2/(pi^2 t_res)
  Largest sphere that can still be SORTED (i.e. that does NOT cross):
      d_max = k_B T / (3 pi eta D_c)   [Stokes-Einstein]

  Case B (COMSOL, Q = 0.1 uL/min):  t_res = 1.8 s
     (i)  D_c = w^2/(8 t_res)      = 6.944444e-10 m^2/s -> d_max = 0.00061839 um
     (ii) D_c = x(t1) w^2/(pi^2 t_res) = 6.517336e-10 m^2/s -> d_max = 0.00065892 um
  Case A (Bruus, L = 25 mm, Q = 0.1 uL/min):  t_res = 7.5 s
     (i)  D_c = w^2/(8 t_res)      = 1.666667e-10 m^2/s -> d_max = 0.0025766 um
     (ii) D_c = x(t1) w^2/(pi^2 t_res) = 1.564161e-10 m^2/s -> d_max = 0.0027455 um
  Sugar itself has D = 2.000e-10 m^2/s, i.e. D/D_c = 0.288
  (classical) - a slow tracer that only partially crosses the 6 mm
  channel within the residence time (consistent with part b).
